# AuraDesign Studio — Free Edition

A free, static taste of the [AuraDesign Studio](https://your-gumroad.gumroad.com/l/auradesign-studio) agency template:
the Home and Portfolio pages with the full interactive effects. No backend, no
build step — just edit and publish.

## Make it yours (no tools needed)

Open the files in a text editor ([VS Code](https://code.visualstudio.com) is
great because it can replace text across every file at once). The quickest
rebrand is Find-and-Replace:

- `AuraDesign` → your brand name
- the accent colour: edit `--accent` at the top of `css/styles.css`
- the demo client names, stats and project text in `index.html` /
  `portfolio.html` (search for `DEMO` to find them)

## Publish

Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag this whole
folder onto the page. You get a live URL in seconds — it's fully static, no
build, no server.
