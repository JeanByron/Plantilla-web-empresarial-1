# AuraDesign Studio

A premium, dark-themed agency & portfolio website template with hand-built
interactive canvas effects, SPA-style navigation, a working contact form, and a
live-style analytics dashboard. Ships in two flavors out of the box: deploy it
as a **100% static site** (no server needed) or run the included **Node/Express
backend** for a real contact form and inquiries dashboard.

## Features

- **Interactive canvas effects** — a mouse-reactive dot mesh, cursor glow,
  light-up 3D-tilt cards, and magnetic buttons, all in vanilla JS (no libraries).
- **SPA navigation** — internal links swap only the `<main>`, keeping the
  animated background alive, with a graceful fallback to full page loads.
- **Analytics dashboard** — custom canvas charts (visits line with tooltip,
  project donut, animated KPIs) with zero charting dependencies.
- **Working contact form** — posts to the bundled Express API *or* a static
  form service (Formspree, etc.), with validation, honeypot, and rate limiting.
- **Dual deployment** — static (Netlify/Vercel/GitHub Pages) or full-stack (Node).
- **English/Spanish ready** — all runtime strings live in one `I18N` dictionary.
- **SEO included** — per-page meta, Open Graph, Twitter Cards, JSON-LD,
  `robots.txt`, and `sitemap.xml`.
- **Accessible** — skip-link, ARIA on interactive controls, reduced-motion
  support, and a `<noscript>` fallback.
- **Original artwork** — all images are original, license-clear SVGs.
- **8 pages** — Home, Portfolio, Services, About + Contact, Dashboard, Case
  Study, 404, and Privacy Policy.

## Requirements

- Node.js 18+ (only needed to build the CSS and, optionally, to run the backend).

## Quick start

Install dependencies and build the CSS:

```bash
npm install
npm run build:css
```

Then pick a deployment mode.

### Option A — Static (no backend)

The `public/` folder is a complete static site. Upload it to Netlify, Vercel,
or GitHub Pages. The portfolio loads from [public/js/projects-data.js](public/js/projects-data.js),
and the contact form can post to a form service:

1. Open [public/js/site-config.js](public/js/site-config.js).
2. Set `formEndpoint` to your Formspree (or similar) endpoint.

That's it — no server required.

### Option B — Full-stack (Node/Express)

Run the bundled server for a live contact form and inquiries dashboard:

```bash
npm start          # production
npm run dev        # auto-restarts on change
```

The site is served at `http://localhost:3000`. Use a different port and protect
the dashboard with an admin key via environment variables (see
[.env.example](.env.example)):

```bash
PORT=3100 ADMIN_KEY=your-secret npm start
```

While editing styles, keep the CSS rebuilding:

```bash
npm run watch:css
```

## API (full-stack mode)

| Method | Route                         | Description                                       |
|--------|-------------------------------|---------------------------------------------------|
| GET    | `/api/projects`               | List portfolio projects                           |
| GET    | `/api/projects?category=web`  | Filter by category (`web`, `branding`, `dev`)     |
| POST   | `/api/contact`                | Submit the contact form (validated, rate-limited) |
| GET    | `/api/inquiries`              | List inquiries (admin key or localhost only)      |
